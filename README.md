# Custom Payload Encoder & Obfuscation Framework

## Overview

This project demonstrates practical payload encoding and string obfuscation techniques used to study static signature evasion in controlled cybersecurity lab environments.

## Features

- Base64 Encoding
- XOR Encoding
- ROT13 Encoding
- String Obfuscation
- Multi-Layer Encoding
- Detection Scoring
- Automated Reporting

## Technologies Used

- Python
- Google Colab
- yara-python
- tabulate

## Workflow

1. Load Payload
2. Apply Encoding
3. Apply Obfuscation
4. Run Detection Simulation
5. Generate Report

## Ethical Notice

This project is intended strictly for educational and defensive cybersecurity research purposes within authorized lab environments.
